# Contributing

Thanks for helping Live Wire.

1. Keep sample data invented. Do not add real people's names to fixtures, demo scripts, or roster copy.
2. Label satire. Do not add UI that presents a rumor as confirmed.
3. Demo mode must keep running with no API keys.
4. Do not commit `.env`, voice caches, or filled archives.
5. Run `python3 -m pytest -q tests` from this folder before opening a pull request.

Code is MIT. If you add third-party assets (voices, fonts, footage), document the license in the pull request.
